# Solución de referencia — sesión 07

> **No abras esta carpeta hasta haber intentado el laboratorio.**
>
> Copiar esto no te va a servir de nada en una entrevista de trabajo, y en el
> proyecto final vas a necesitar escribir tu propio stack desde cero.

Contiene un `compose.yml` funcional con Jupyter, Postgres (esquemas `cdm` y `results`)
y Adminer, más los scripts de inicialización de la base.

Úsalo para:

- Comparar tu solución con una alternativa, después de terminar la tuya
- Entender una construcción concreta que no lograste resolver
- Consultar la sintaxis de `healthcheck`, `depends_on` o `profiles`

No lo uses para:

- Entregar el laboratorio
- Saltarte el ejercicio

Si tu solución difiere de ésta, no significa que esté mal. Hay varias formas
razonables de armar el mismo stack.
