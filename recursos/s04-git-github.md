# Material complementario — Sesión 04

## Control de Versiones con Git y GitHub

*Bloque II — Ingeniería de software para científicos*

> Los recursos marcados con **★** son los que conviene revisar antes de la clase.
> El resto es para profundizar según tu interés y tu proyecto.

## Objetivos que apoya este material

- Explicar el modelo de datos de Git (blob, tree, commit, ref) y por qué eso hace que todo lo demás tenga sentido
- Usar ramas, merge y rebase con criterio, y resolver conflictos sin pánico
- Colaborar vía pull requests con revisión de código
- Configurar un repositorio de investigación reproducible con README, licencia y CI básica

## Libro de referencia

- ★ [**Pro Git (Chacon & Straub) — 2ª ed.**](https://git-scm.com/book/en/v2)
  Gratis, completo, el libro oficial. Capítulos 1–3 y 7 son los relevantes.
- [**Pro Git en español**](https://git-scm.com/book/es/v2)
  Misma obra, traducida.

## Práctica interactiva

- ★ [**Learn Git Branching**](https://learngitbranching.js.org/?locale=es_ES)
  Visualizador interactivo de ramas. La mejor forma de entender rebase. Disponible en español.
- [**GitHub Skills**](https://skills.github.com/)
  Cursos cortos y prácticos dentro del propio GitHub.
- [**Oh My Git!**](https://ohmygit.org/)
  Juego de cartas de escritorio para aprender Git. Gratis y sorprendentemente bueno.

## Rescate y errores

- ★ [**Dangit, Git!?!**](https://dangitgit.com/es)
  Recetario de 'la regué, ¿cómo lo arreglo?'. En español.
- [**git-flight-rules**](https://github.com/k88hudson/git-flight-rules)
  Guía exhaustiva de qué hacer cuando algo sale mal.

## Convenciones y calidad

- ★ [**Conventional Commits**](https://www.conventionalcommits.org/es/v1.0.0/)
  Especificación de mensajes de commit estructurados.
- [**How to Write a Git Commit Message (Chris Beams)**](https://cbea.ms/git-commit/)
  Las 7 reglas. Corto y definitivo.
- [**Semantic Versioning**](https://semver.org/lang/es/)
  MAJOR.MINOR.PATCH y qué significa cada uno.

## Investigación reproducible

- ★ [**The Turing Way — Version Control**](https://book.the-turing-way.org/reproducible-research/vcs)
  Guía comunitaria de ciencia de datos reproducible. Excelente y en constante actualización.
- [**CITATION.cff — Citation File Format**](https://citation-file-format.github.io/)
  Para que citen tu código correctamente.
- [**Zenodo + GitHub**](https://docs.github.com/en/repositories/archiving-a-github-repository/referencing-and-citing-content)
  Cómo obtener un DOI para tu repositorio.
